# 中文内容合规检查 MCP Server

把中文内容合规检查能力接入 AI Agent —— Claude Desktop / Cursor / Cline 等可直接调用，
无需人工转述。

**零外部依赖**：有官方 `mcp` 库时用官方实现；没有则自动降级为内置 stdio JSON-RPC，
功能完全相同。`pip install` 都不需要就能跑。

---

## 它解决什么问题

写中文商业内容（电商详情页、短视频文案、公众号文章、AI 生成图文）时，
最容易踩的三个坑：

1. **广告法违禁词** —— 「全网最」「100%」「国家级」「根治」「包过」「稳赚不赔」
2. **AI 生成内容标识** —— 《人工智能生成合成内容标识办法》要求显式标识 + 隐式元数据标识
3. **组织流程缺失** —— 有没有做安全评估、算法备案、单独同意

本 Server 把这三类检查暴露为 3 个 MCP 工具，Agent 可以在你写作时**直接调用并给出依据法条**。

---

## 提供的工具

| 工具 | 作用 | 输入 |
|---|---|---|
| `check_content` | 检查文本合规风险，返回逐条：类型 / 位置 / 命中文本 / **依据法条** / 修改建议 | `text` |
| `check_ai_label` | 判断是否需按《AI 生成合成内容标识办法》加标识（显式 / 隐式） | `text` |
| `self_assessment` | 17 项组织级合规自查问卷 → 覆盖率评分 + 待整改清单 | `answers` |

### 覆盖的法规依据

- 《中华人民共和国广告法》第 9 条（绝对化用语）、第 13 条（贬低同行）、
  第 16 条（治愈率）、第 17 条（疾病治疗功能）、第 18 条（保健食品）、
  第 24 条（教育效果承诺）、第 25 条（金融收益承诺）、第 28 条（虚假广告）
- 《人工智能生成合成内容标识办法》第 4、5 条 + 强制性国标 GB 45438-2025
- 《食品安全法》第 73 条 · 《反不正当竞争法》第 11 条

## 安装

### 方式一：Claude Desktop

编辑配置文件（Windows：`%APPDATA%\Claude\claude_desktop_config.json`；
macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`）：

```json
{
  "mcpServers": {
    "wanhe-compliance": {
      "command": "python",
      "args": ["/绝对路径/mcp_compliance_server.py"]
    }
  }
}
```

重启 Claude Desktop，在工具列表中即可看到 `check_content` / `check_ai_label` /
`self_assessment`。

### 方式二：Cursor / Cline / 其他 MCP 客户端

在对应的 MCP 配置里加入同样的 `command` + `args` 即可（均为 stdio 传输）。

### 方式三：直接命令行验证

```bash
python mcp_compliance_server.py --selftest
```

会输出引擎加载状态、工具清单，并用一段示例文本跑一次检查。

## 设计原则（重要）

### 1. 宁可漏检，不可误报

合规工具**误报一次就会失去信任**。所以规则要求**语境同现**：

- 只有「功效声明 + 疾病名」同时出现才判定（如「适用于高血压」）
- 单独的疾病名**不报**（如「高血压患者请在医师指导下用药」是正当提示）
- 「康复器材」「康复中心」等**合法商品与机构名不报**

### 2. 不编造问题

未发现问题时明确返回「未发现上述规则覆盖的问题」，**不会为了显得有用而虚报**。

### 3. 可复现

同输入必同输出（规则引擎而非模型判断）。

## 自己测：27 例中文基准集（可下载）

我们的规则引擎不是"感觉准"，而是有一份**可复现的评测集**：

**https://wanhetools.top/bench**

27 个真实中文句子，按语义分 5 类，每例都标注「期望值 + 为什么这么标 + 引擎实际输出」：

| 类别 | 例数 | 含义 | 期望 |
|---|---|---|---|
| `true-positive` | 11 | 真违规（有商业语境） | 必须报 risk |
| `false-positive` | 8 | **正常中文用语** | **不该报** |
| `meta-discourse` | 3 | 讲解/列举违禁词 | 降级 |
| `quoted-region` | 4 | 表格/代码块内示例 | 降级 |
| `legal-context` | 1 | 复述法条原文 | 降级 |

**为什么需要它**：裸词表在正常中文里会大量误报 —— 实测 12 个句子里累计命中 17 次，
其中在 **7 个完全正常的句子上 7/7 全部误报**（「最新/最终」「兜底」「彻底解决」等）。
**误杀率不是精度问题，是产品还能不能被用的问题。**

把它拿去测你自己的词表，重点看 `false-positive` 那 8 例：那是"不该报"的，报了就是误杀。
